# wo — 个人知识库 / Second Brain

个人知识库,收录计算机技术、生活技能、创业思考与读书笔记。

## 在线访问

<https://hanyudeye.github.io/wo/>

基于 GitHub Pages + Jekyll(minimal 主题)自动发布,推送到 `main` 分支即更新。

## 内容结构

| 目录            | 内容                                     |
|-----------------|------------------------------------------|
| `computer/`     | 计算机技术(编程、Linux、Emacs、AI、工具) |
| `living/`       | 生活知识(语言学习、健康、心理、烹饪)     |
| `startup/`      | 创业与赚钱(AI 产品、投资、商业)          |
| `books/`        | 读书笔记                                 |
| `technologies/` | 技术专题                                 |
| `scripts/`      | Python 脚本、n8n 工作流、AHK 等          |

## 写作惯例

- 内容以中文为主,文件名可中英混用
- 文件是知识卡片,不是教程,保持简短、实用
- 标题用 `##` / `###`,列表用 `-`
- 新笔记放入对应分类目录,拿不准就放最相关的目录
