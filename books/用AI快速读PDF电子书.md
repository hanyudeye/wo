# 用 AI 快速读 PDF 电子书

读不进去整本书时，分三个层次交给 AI。

## 方法 1：直接上传 PDF（最快）

选支持长上下文的对话模型，PDF 直接拖进去：

- **KIMI** — 中文书首选，200 万字上下文，300 页的书一次读完
- **ChatGPT / Claude** — 英文书效果好
- **豆包 / DeepSeek** — 也可

## prompt 模板（不要只说"总结这本书"）

```
我读不进去这本《XXX》，请帮我：
1. 先看目录，标出哪几章是核心、哪几章可以跳过（二八法则）
2. 按章节给提纲：每章 3-5 个核心观点 + 一个具体例子
3. 提炼全书 10 个最重要的结论，每条一句话 + 适用场景
4. 列出关键概念表：术语 / 一句话解释
5. 出 5 道测试题检验我是否真懂
```

读完每一章再追问一轮效果更好：**"我读完了第 3 章，用问题考我，看我哪里没懂。"**（费曼学习法）

## 方法 2：超长书或扫描版 — 先转文本再喂

超大 PDF 大模型往往只读前面几十页，需先转 Markdown 分块喂：

- 文本型 PDF：`pdftotext`（poppler）或 Calibre 转 txt
- 扫描版 / 公式多的书：**MinerU**、**Marker**、**Mathpix**，识别成 Markdown 保留下标公式
- 微信读书的书：导出到电脑后同上处理

## 方法 3：长期读的话，建知识库（RAG）

n8n 做一条流水线：上传 PDF → 切片 → 入库 → 问答，之后随时问某章讲了什么，不用重复上传（参考 `技术/编码术/n8n工作流从零到业务交付.md` 知识库问答）。

## 建议

从**方法 1 + prompt 模板**开始，一本书约 20 分钟拿到"可读版"。
