# GitHub 开源项目学习清单

> 面向初学者的实用项目，分"容易入门"和"深入进阶"两档，附作者联系方式。
> 邮箱均为项目方公开信息；未公开个人邮箱的社区项目，统一走 GitHub Issue/Discussion 联系。

## 容易入门

### firstcontributions/first-contributions
- 地址：https://github.com/firstcontributions/first-contributions
- 用途：教你 5 分钟完成第一次开源贡献——Fork、Clone、提 PR 全套流程走一遍，Git/开源协作零基础起点。
- 作者：Roshan Jossey（GitHub: @Roshanjossey），个人邮箱未公开
- 联系：项目 Issue/Discussion，或 https://roshanjossey.github.io

### TheAlgorithms/Python
- 地址：https://github.com/TheAlgorithms/Python
- 用途：22 万 star 的算法全家桶，排序/搜索/动态规划/机器学习等 80+ 算法 Python 实现，适合对着源码学算法和代码规范。
- 维护：社区共建，官方邮箱 **hello@the-algorithms.com**
- 联系：说明见上；技术问题提 Issue

### practical-tutorials/project-based-learning
- 地址：https://github.com/practical-tutorials/project-based-learning
- 用途：按"动手做一个东西"来学编程——网页、游戏、命令行工具、解释器……几百个教程按语言分好类，学完即作品。
- 维护：社区项目，无个人作者邮箱
- 联系：GitHub Issues

### EbookFoundation/free-programming-books
- 地址：https://github.com/EbookFoundation/free-programming-books
- 用途：免费编程书/课程/播客的巨型导航目录，十几万 star。想找哪门语言、哪个方向的资料，先来这。
- 维护：社区项目（超级老牌）
- 联系：GitHub Issues

## 深入进阶

### freeCodeCamp/freeCodeCamp
- 地址：https://github.com/freeCodeCamp/freeCodeCamp
- 用途：完整的免费全栈课程（HTML→JS→React→Node→数据库），边学边做真实项目，还有论坛/社区能提问。课程全认证免费。
- 创始人：Quincy Larson，官方联系邮箱 **quincy@freecodecamp.org**（官网公开）
- 联系：技术支持提问走 https://forum.freecodecamp.org

### kamranahmedse/developer-roadmap
- 地址：https://github.com/kamranahmedse/developer-roadmap
- 用途：前端/后端/DevOps/AI 等各方向的完整学习路线图（配套 site：roadmap.sh），进阶时用来做技术栈选型、查缺补漏。
- 作者：Kamran Ahmed（GitHub: @kamranahmedse），公开邮箱 **kamranahmed.se@gmail.com**
- 联系：见 roadmap.sh/about

### danistefanovic/build-your-own-x
- 地址：https://github.com/danistefanovic/build-your-own-x
- 用途："重造轮子"式深入理解——自己写一个 Git、数据库、正则引擎、网络爬虫、操作系统……弄懂底层原理，进阶最好的方式。
- 作者：Daniel Stefanovic（瑞士，创始人），个人邮箱未公开
- 联系：GitHub Issues，或 https://codecrafters.io

### TheOdinProject/curriculum
- 地址：https://github.com/TheOdinProject/curriculum
- 用途：系统性的全栈课程（Ruby + 前端 JS），比 freeCodeCamp 更硬核，作业全是实打实的项目，做完简历有东西写。
- 维护：社区课程团队，无个人作者邮箱
- 联系：官方 Discord 社区（见项目 README）

## 使用建议

- 入门选 1-2 个就够：**firstcontributions 走一遍 PR + TheAlgorithms/Python 读算法**
- 进阶跟着 **freeCodeCamp 或 The Odin Project** 挑一条线学到底
- 别囤清单：收藏 5 个不如啃完 1 个
