# macOS 多窗口布局与切换

程序员在 MacBook 上通常开 3~5 个窗口，用「多桌面 + 快捷键」管理。

## 常见开窗组合

- **编辑器**：VS Code / Neovim / JetBrains —— 写代码的主力
- **终端**：iTerm2 / Terminal —— 跑命令、git、服务
- **浏览器**：Chrome / Safari —— 查文档、看效果
- **沟通**：Slack / 微信 / 钉钉
- **杂项**：DB 客户端、设计稿、播放器

## 切换窗口快捷键

| 操作           | 快捷键                 | 效果                       |
|----------------|------------------------|----------------------------|
| 切换应用       | `Cmd + Tab`            | 最近使用的应用之间跳转     |
| 同应用内切窗口 | `Cmd + ~`              | 多个 VS Code 窗口间切换    |
| 切换桌面 Space | `Ctrl + ← / →`       | 左右滑动不同桌面           |
| 桌面总览       | `Ctrl + ↑` 或三指上滑 | Mission Control 看所有桌面 |
| 聚焦搜索       | `Cmd + Space`          | Spotlight 快速启动应用     |

## 典型布局

**方案一：单屏两分（最简单）**

```
┌─────────────────┬──────────────────┐
│    编辑器        │     浏览器        │
│   (代码主区)     │   (文档/预览)     │
└─────────────────┴──────────────────┘
```

`Cmd + Ctrl + 左右方向键` 把窗口贴到半屏。

**方案二：三窗口 + 终端（最常见的程序员布局）**

```
┌────────────────────┬──────────┬────────┐
│       VS Code       │  终端    │ 浏览器  │
│                     │  (跑服务) │ (日志)  │
└────────────────────┴──────────┴────────┘
```

**方案三：多桌面分离（推荐，屏幕不挤）**

- **桌面 1**：编辑器 + 终端（专注写码）
- **桌面 2**：浏览器（查文档）
- **桌面 3**：Slack + 邮件（沟通）
- 用 `Ctrl + ←/→` 在三个桌面间滑，比硬塞一个屏舒服得多

## 进阶工具

- **Raycast / Alfred**：替代 Spotlight，搜应用、剪贴板、窗口管理
- **Rectangle / yabai**：窗口贴边分屏快捷键
- **iTerm2 分屏**：`Cmd + D` 竖向、`Cmd + Shift + D` 横向，一个终端开多个面板

## 关键习惯

不要把所有窗口堆在一个桌面，善用「多桌面 + `Cmd+Tab`」，效率和专注度都会明显提升。
