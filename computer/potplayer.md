# potplayer 如何进行a-b 循环学习英语


PotPlayer 的 A-B 循环功能非常适合英语学习（反复听某段音频/视频），操作如下：

### 快捷键（默认）
- **`[`**：设置循环起点 A
- **`]`**：设置循环终点 B
- **`\`**（反斜杠）：清除/取消 A-B 循环

### 操作步骤
1. 播放视频/音频，播放到要重复的句子开头时，按 `[` 设置起点。
2. 播放到句子结尾时，按 `]` 设置终点。
3. 此时播放器会自动在这段区间内循环播放。
4. 按 `\` 取消循环，继续正常播放。

### 辅助技巧（学英语）
- 配合 **`Shift + 方向键`** 或 **`Ctrl + 方向键`** 可以逐帧/微调起止点，精确定位。
- 在播放界面右键 → **播放** → **A-B 段重复** 也可以看到相关选项。
- 如果想放慢语速，按 **`Z`** 键（或 Shift+Z）可以切换播放速度（如 0.7、0.8 倍速）。

这样你就可以反复精听某个句子，直到听清每个单词。
