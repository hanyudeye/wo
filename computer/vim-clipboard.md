# Vim 复制到系统剪贴板

让 Vim 与系统剪贴板（浏览器、终端、其他编辑器）互通。

## 前置检查

Vim 必须支持剪贴板（`+clipboard`）：

```bash
vim --version | grep clipboard
# +clipboard 表示支持
# -clipboard 表示不支持（需换带剪贴板的版本或桥接）
```

Ubuntu/Debian 默认的 `vim.basic` / `vim.tiny` 通常是 `-clipboard`。

## 方法一：安装 vim-gtk3（推荐）

自带剪贴板支持，一步到位：

```bash
sudo apt install vim-gtk3
sudo update-alternatives --config vim   # 选 vim.gtk3
```

## 方法二：clipboard provider 桥接（不装东西时）

Vim 有 `+clipboard_provider` 时，可用外部工具桥接。添加并写入 `~/.vimrc`：

Wayland（wl-clipboard）：
```vim
let g:clipboard = {
      \ 'name': 'wl-clipboard (wayland)',
      \ 'copy': { '+': ['wl-copy'], '*': ['wl-copy'] },
      \ 'paste': { '+': ['wl-paste', '--no-newline'], '*': ['wl-paste', '--no-newline'] },
      \ }
```

X11（xclip 或 xsel）：
```vim
let g:clipboard = {
      \ 'name': 'xsel (x11)',
      \ 'copy': { '+': ['xsel', '-ib'], '*': ['xsel', '-ib'] },
      \ 'paste': { '+': ['xsel', '-ob'], '*': ['xsel', '-ob'] },
      \ }
```

## 让 y / p 直接用系统剪贴板

即使支持剪贴板，默认 `y` 复制的是 Vim **内部寄存器** `"0`，不会进系统剪贴板。要改变这个行为：

```vim
set clipboard=unnamedplus   " y / p 直接映射到系统剪贴板（+寄存器）
```

### 常用操作

| 操作 | 说明 |
|---|---|
| `"+y` | 复制选中内容到系统剪贴板 |
| `"*y` | 复制到 X 主选择区（中键粘贴） |
| `"+p` | 粘贴系统剪贴板内容 |
| `set clipboard=unnamedplus` 后 `y` / `p` | 直接读写系统剪贴板 |
| `"ay` / `"ap` | 存到寄存器 a，不污染剪贴板 |

### amix vimrc 注意事项

如果 `~/.vimrc` 是 amix 配置（文件头写着 DO NOT EDIT THIS FILE），
自定义配置写入 `~/.vim_runtime/my_configs.vim`：

```vim
" 让 y / p 直接使用系统剪贴板
set clipboard=unnamedplus
```

## 常见问题

**Q: `y` 复制了但贴不进浏览器？**
- 检查 `vim --version | grep clipboard` 是否为 `+clipboard`
- 检查是否已 `set clipboard=unnamedplus`
- 尝试显式 `"+y`

**Q: Wayland 下剪贴板为空？**
- 确认会话类型：`echo $XDG_SESSION_TYPE`
- Wayland 用 wl-clipboard（`wl-copy` / `wl-paste`），X11 用 xsel/xclip
