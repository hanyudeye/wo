# 我有一个游戏手柄，并下载了映射软件，我的需求是想躺在沙发上，利用手柄尽可能的操控电脑，可以语音输入，控制视频播放，暂停，有什么理想的配置方案

你的需求本质上是在做一个 **"10-foot UI（客厅电脑）+ 遥控器 + 语音助手"**。游戏手柄只是输入设备之一，真正的目标是：**不用起身，完成 95% 的电脑操作。**

我推荐的方案分为四层，从稳定性和可扩展性来说都比较成熟。

## 语音部分实战方案（Linux）

基于上面的推荐，以下是**可直接部署的语音方案**，核心是"按住手柄按钮说话，松开即转文字并执行操作"。

### 方案一：Whisper.cpp 命令行方案（推荐，完全本地）

```
依赖：whisper.cpp + AutoKey + ydotool/wtype
```

#### 1. 编译 whisper.cpp

```bash
git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp
make -j
# 下载模型（推荐 small 或 medium，平衡速度和准确度）
bash models/download-ggml-model.sh small
make -j
```

#### 2. 录音脚本

```bash
#!/bin/bash
# ~/.local/bin/voice_input.sh

MODEL="$HOME/whisper.cpp/models/ggml-small.bin"
FILE="/tmp/voice_input.wav"
TEXT_FILE="/tmp/voice_text.txt"

# 开始录音
arecord -f cd -t wav -d 3 "$FILE"  # 3秒录音，可调整

# 转文字
$HOME/whisper.cpp/main -m "$MODEL" -f "$FILE" -otxt -of "$TEXT_FILE" 2>/dev/null

# 输出到当前焦点窗口
text=$(cat "$TEXT_FILE.txt")
wtype "$text"
```

#### 3. 用 AutoKey 绑定到手柄

在 AutoKey 中创建一个脚本，调用 `voice_input.sh`，然后绑定到手柄的一个按键组合（如 Start+X）。

### 方案二：Vosk + Python（轻量，响应更快）

```
依赖更小，不需要 GPU，CPU 也能跑
```

#### 安装

```bash
pip install vosk sounddevice keyboard
```

#### Python 脚本

```python
#!/usr/bin/env python3
# ~/.local/bin/voice_input_vosk.py

import sounddevice as sd
import vosk
import json
import subprocess
import sys
import queue

MODEL_PATH = "~/vosk-model-small-cn-0.22"  # 中文模型，英文用 vosk-model-small-en-us-0.15

model = vosk.Model(MODEL_PATH)
q = queue.Queue()

def callback(indata, frames, time, status):
    q.put(bytes(indata))

with sd.RawInputStream(samplerate=16000, blocksize=8000, dtype='int16',
                       channels=1, callback=callback):
    rec = vosk.KaldiRecognizer(model, 16000)
    while True:
        data = q.get()
        if rec.AcceptWaveform(data):
            result = json.loads(rec.Result())
            text = result.get("text", "")
            if text:
                # 用 ydotool/wtype 输入到当前窗口
                subprocess.run(["wtype", text])
                break
```

绑定到手柄按键（通过 AntiMicroX 启动此脚本）。

### 方案三：语音命令版（不需要屏幕键盘）

直接识别命令并执行操作，而不是输入文字：

```python
# voice_command.py
# 按住 LB 说话："打开浏览器"、"播放/暂停"、"音量加"等

import subprocess
import json
import vosk
import sounddevice as sd
import queue

model = vosk.Model("~/vosk-model-small-cn-0.22")
q = queue.Queue()

COMMANDS = {
    "打开浏览器": "google-chrome",
    "播放": "playerctl play-pause",
    "暂停": "playerctl play-pause",
    "下一首": "playerctl next",
    "上一首": "playerctl previous",
    "音量加": "pactl set-sink-volume @DEFAULT_SINK@ +5%",
    "音量减": "pactl set-sink-volume @DEFAULT_SINK@ -5%",
    "静音": "pactl set-sink-mute @DEFAULT_SINK@ toggle",
    "全屏": "wtype -k F11",
    "退出": "wtype -k Escape",
}

def callback(indata, frames, time, status):
    q.put(bytes(indata))

with sd.RawInputStream(samplerate=16000, blocksize=8000, dtype='int16',
                       channels=1, callback=callback):
    rec = vosk.KaldiRecognizer(model, 16000)
    while True:
        data = q.get()
        if rec.AcceptWaveform(data):
            result = json.loads(rec.Result())
            text = result.get("text", "")
            for cmd, action in COMMANDS.items():
                if cmd in text:
                    subprocess.run(action.split())
                    break
            break
```

### 推荐硬件

| 设备 | 用途 |
|------|------|
| 领夹麦（几块钱） | 远场收音，比笔记本内置麦克风好太多 |
| 带静音按钮的 USB 麦克风 | 按一下静音，防止误触发 |

### 整体绑定建议

```
手柄按键         → 功能
─────────────────────────────
LB+右摇杆按下     → 启动语音输入（录音→转文字→输入）
LB+Start        → 启动语音命令（识别命令并执行）
LT+十字键上/下   → 音量加减
RT+十字键左/右   → 上一首/下一首
```

优先推荐 **方案一（Whisper.cpp）**，准确度最高。如果想要更低延迟、更轻量的方案，用 **方案二（Vosk）**。如果只用来控制播放/打开应用，**方案三（语音命令）** 最稳定。
