# 实用论坛 / 社区推荐

计算机实用配置、好应用推荐的信息源。

## 国内

- **V2EX**（v2ex.com）— 极客聚集地，App 推荐、效率工具话题多
- **少数派**（sspai.com）— 效率工具、Apple 生态文章质量高，类似杂志
- **知乎** — 搜「效率工具」「Mac 配置」等话题
- **Chiphell**（chiphell.com）— 硬件、桌面、外设
- **什么值得买**（smzdm.com）— 硬件性价比

## 国外（英文）

- **r/unixporn** — Linux / 终端美化，iTerm2 配置灵感来源
- **r/macapps**、**r/productivity**、**r/selfhosted**
- **Hacker News**（news.ycombinator.com）— 技术深度内容
- **Lobsters**（lobste.rs）
- **YouTube**：NetworkChuck、Chris Titus Tech

## 首选

- 中文、接地气 → **V2EX**
- 成体系、文章向 → **少数派**
- 玩 Mac + iTerm2 → V2EX 搜「Mac 必备软件」
