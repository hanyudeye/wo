# 语音输入方案

## MacBook Siri 语音控制

**可用性：中上。** 适合轻度使用，重度输入建议用第三方工具。

- **系统听写（Dictation）**：按两下 Fn（或 Control）启动，中英文识别中上，短段好用，长文不稳定
- **Siri 语音控制**：可全系统操作（打开 App、点击、滚动），但延迟偏高，准确率不如专用引擎
- **缺点**：不能自定义热词、不支持离线大模型、长文识别会超时断开

推荐替代：[Voicebox](voicebox.md) — 本地 Whisper 引擎，Push-to-Talk，隐私安全

---

## Windows 替代方案

### 1. CapsWriter 离线版（推荐）

- 开源本地，Whisper 引擎
- 按住大写锁定键说话，松手自动转文字并输入
- 支持自定义热词
- 100% 离线，隐私安全
- 详见 [capswriter-offline.md](capswriter-offline.md)

### 2. Windows 自带 Win+H 语音输入

- 按 `Win+H` 启动，中英文都支持
- 需要联网，准确率尚可
- 长文输入不稳定，无热词功能

### 3. 讯飞/百度输入法语音

- 云端识别，准确率最高之一
- 隐私有顾虑（语音上传服务器）
- 适合不在意隐私的场景

### 4. Voicebox

- 开源本地，macOS + Windows 双平台
- 听写模式：全局快捷键，说话自动粘贴
- TTS 和声音克隆功能
- 详见 [voicebox.md](voicebox.md)

## 总结

| 平台 | 首选方案 | 理由 |
|------|----------|------|
| macOS | **Voicebox** | 本地 Whisper，全局 Push-to-Talk，隐私好 |
| Windows | **CapsWriter 离线版** | 本地离线，按住说话松手出字，国产优化好 |
| 两者皆可 | Voicebox | 跨平台统一体验 |
| 不介意隐私 | 讯飞输入法语音 | 云端识别最准 |

## 语音 vs 打字对思维的影响

语音比打字更能保持思路流畅，避免打字打断思维：

**语音的优势：**
- **语速 ≈ 思维速度** — 说话 150 词/分钟 vs 打字 40-60 词/分钟，思维不易中断
- **降低"编辑冲动"** — 打字时手慢于脑，容易边打边改，打断思路流；语音没有退格键，迫使你专注输出而非润色
- **占用视觉/手部资源少** — 打字占用手和眼，语音只占用听觉/口语通道，可以边走动边思考
- **更接近"自然思考"** — 大多数人的思考本质是"内心对话"，语音输出是最直接的映射

**语音的局限：**
- 不适合**结构化写作**（代码、表格、复杂逻辑）— 打字可以随时跳跃修改，语音是线性的
- 需要**后期编辑** — 语音产生的文字通常较口语化、冗余，需要润色
- 环境受限 — 公共场合不方便

**最佳实践：** 写初稿/头脑风暴用语音，整理/修改用打字，各取所长。
