# 一技之长

## 前提

没有任何人知道未来 5-10 年什么技能"一定"赚钱。所有预测都是猜的。以下是我自己的判断，不是事实。

## 我现在的情况

- 计算机专业，对 AI 感兴趣
- 会折腾工具（WSL、Spacemacs、Python）
- 想做副业，愿意长期投入
- 英语能读技术文档，但不够用

## 最值得投入的方向

按我自己的优先级排：

1. **动手做东西的能力** — 比"学什么"重要一百倍。能独立把想法变成可用的东西（网页、自动化脚本、AI 工具），这是最硬的技能
2. **英语** — 技术圈最好的资料、最新的工具、最大的市场都是英文的。英语好等于比别人多一倍的资源
3. **Linux / 命令行** — 已经在用了，继续深入。几乎所有 AI 基础设施都跑在 Linux 上
4. **Python + API 调用** — 粘合一切。n8n、AI Agent、自动化脚本都离不开
5. **Node.js / 前端** — 能自己做完整产品，不用求人

## 书

书只是工具，要带着项目去读，不要为了读书而读书。

我真正读完并且觉得有用的：

- *Automate the Boring Stuff with Python* — Python 自动化入门，实用
- *The Linux Command Line* — Linux 入门，配合 WSL 边用边看
- *Python for Data Analysis* — Pandas 作者写的，做数据处理绕不开
- *English Grammar in Use* — 语法查缺补漏，不需要全读

想读还没读的：
- *DDIA* — 分布式系统经典，等基础够再看
- *Node.js Design Patterns* — 等开始认真写 Node 再读

## 关于副业

坦率说，我现在还没有稳定的副业收入。方向感觉是对的（AI 自动化、企业知识库、n8n 工作流），但"感觉对"和"能赚钱"之间还差执行。

下一步具体动作：
- 用 n8n 做一个完整的自动化工作流（哪怕自用的）
- 搞清楚 Dify/DeepSeek 搭知识库的完整流程
- 在 GitHub 上发一个实际项目，而不是继续读书
