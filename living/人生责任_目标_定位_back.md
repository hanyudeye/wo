# 人生三问：责任 · 目标 · 定位

> 人生的困惑无非三个问题：**要还什么债**（责任）、**要去哪里**（目标）、**我是谁**（定位）。三者互为基石，缺一不可。

---

## 一、人生责任

责任不是别人强加给你的枷锁，而是你选择某种角色后自然产生的**义务集合**。

### 1.1 责任的四个圈层

```
         ┌─────────────┐
         │  对生命本身  │  最内核：活着、成长、不辜负自己的存在
         ├─────────────┤
         │   对自我     │  第二层：健康、能力、情绪、财务
         ├─────────────┤
         │   对家庭     │  第三层：伴侣、父母、子女
         ├─────────────┤
         │   对社会     │  最外层：职业、社区、陌生人、环境
         └─────────────┘
```

**越内层越不可推卸，越外层越量力而行。**

### 1.2 核心责任清单

| 责任类型 | 具体内容 | 是否可选 |
|---------|---------|---------|
| **对自己的责任** | 保持身心健康、持续成长、管理财务、对自己诚实 | 不可选 |
| **对家人的责任** | 经济支持、情感陪伴、关键决策时的在场 | 部分可选（取决于你是否选择组建家庭） |
| **对职业的责任** | 交付价值、专业精神、对得起拿到的报酬 | 不可选（如果选择工作） |
| **对社会的责任** | 不伤害他人、力所能及地回馈、遵守底线规则 | 最低不可选，高可选项 |

### 1.3 常见的责任误区

- **过度负责**：把别人的课题背在自己身上（参见阿德勒"课题分离"）
- **逃避责任**：用自由的名义拒绝所有义务，结果是失去信任和关系
- **混淆责任与期望**：父母/社会对你的期望 ≠ 你的责任

### 1.4 判断责任的标准

一个责任是否真的是你的，问三个问题：
1. 这个角色是我主动选择的吗？（选择带来责任）
2. 如果不承担，谁会受伤？伤害程度多大？
3. 有没有人比我更适合承担这个责任？

> 责任的上限是**能力**，责任的下限是**良知**。

## 二、人生目标

目标是**将注意力集中到特定方向上**的工具。没有目标，精力就会消散。

### 2.1 目标的分层

```
        ┌──────────────┐
        │  终极目标     │  人生意义/使命（Why）
        ├──────────────┤
        │  长期目标     │  5-10 年的大方向（Where）
        ├──────────────┤
        │  中期目标     │  1-3 年的阶段成果（What）
        ├──────────────┤
        │  短期目标     │  本季/本月/本周（How）
        └──────────────┘
```

### 2.2 人生目标的六大维度

健康 · 关系 · 事业 · 财富 · 成长 · 贡献

**不要试图六个维度同时满分。** 每个阶段的侧重点不同：

| 人生阶段 | 优先维度 | 次要维度 |
|---------|---------|---------|
| 20-30 岁（探索期） | 成长、事业 | 关系、健康 |
| 30-45 岁（建立期） | 事业、财富、关系 | 健康、贡献 |
| 45-60 岁（成熟期） | 关系、贡献、健康 | 财富、成长 |
| 60+ 岁（收获期） | 健康、贡献、关系 | 成长 |

### 2.3 如何找到自己的目标

如果你不知道想要什么，先从**排除法**开始：

1. **排除法**：明确不想要什么（比明确想要什么更容易）
2. **遗憾测试**：想象 80 岁的自己，最遗憾没做什么
3. **能量追踪**：记录什么让你进入心流状态
4. **最小实验**：不需要想清楚全部，先花 100 小时试试

### 2.4 目标设定的原则

- **少即是多**：同时追逐太多目标等于没有目标
- **以终为始**：先想清楚终点，再倒推路径
- **系统 > 目标**：目标是结果，系统是过程。建立日课系统，目标自然会到来
- **灵活调整**：目标不是刻在石头上的，根据信息更新

> 目标是方向，不是牢笼。

## 三、人生定位

定位是回答：**我是谁？我在哪？我往哪去？以什么方式去？**

### 3.1 定位的三要素

```
         ┌──────────────┐
         │   优势        │  你擅长什么（能力）
         ├──────────────┤
         │   价值        │  你能提供什么（贡献）
         ├──────────────┤
         │   生态位      │  你在什么场景下对什么人有用（环境）
         └──────────────┘
```

**定位 = 优势 × 价值 × 生态位**

三者缺一不可：有优势没价值是自嗨，有价值没优势是竞争红海，都有但没有生态位是怀才不遇。

### 3.2 四种人生定位模式

| 模式 | 描述 | 适合人群 | 风险 |
|------|------|---------|------|
| **深耕型** | 在一个领域做到前 10% | 专注力强的人 | 领域过气 |
| **跨界型** | 在两个领域做到前 25%，交汇处独特 | 好奇心强的人 | 精力分散 |
| **平台型** | 连接资源和人才，做赋能者 | 社交能力强者 | 自身缺乏壁垒 |
| **自由型** | 保持灵活，不绑定任何单一身份 | 追求自由的人 | 缺乏积累效应 |

### 3.3 定位的误区

- **定位是静态的**：错，定位需要不断调整。人是发展的
- **定位就是标签**：错，定位不是给自己贴个标签就完了
- **定位由别人决定**：错，最终是你自己选择
- **先定位再行动**：错，很多时候是行动中才找到定位的

### 3.4 定位的实操方法

**第一步：盘点资产**
- 技能资产：你会什么
- 经历资产：你做过什么
- 认知资产：你懂什么别人不懂的
- 关系资产：你认识谁
- 性格资产：你的性格适合什么

**第二步：找到交汇点**

```
      你喜欢什么？
           ↓
  你擅长什么？ → 交汇点 → 市场需要什么？
           ↑
      能赚到什么？
```

**第三步：最小化验证**
不需要彻底想明白再行动。在一个小范围内测试定位，看反馈，调整。

### 3.5 定位的终极问题

> 问：如果没有任何限制（钱、面子、他人评价），你会怎么过这一生？
>
> 问：如果只能活一年，你会怎么过？
>
> 问：你希望你的墓志铭上写什么？

这三个问题的交集中，藏着你的真实定位。

## 四、三者的关系

```
    责任 ───── 目标
       ╲      ╱
        定位
```

- **定位不清** → 责任和目标都混乱
- **责任不明** → 目标容易被外界牵着走
- **目标不定** → 责任变成负担，没有方向

**三者的动态平衡：**

| 状态 | 症状 | 解决方向 |
|------|------|---------|
| 责任过重 | 被义务压垮，没时间思考 | 用定位筛选责任 |
| 目标过大 | 理想丰满现实骨感 | 用责任校准目标 |
| 定位模糊 | 东一榔头西一棒子 | 先用目标带动定位 |

---

## 五、一句话总结

- **责任**：要还的债，选的角色，承担的后果
- **目标**：想去的地方，阶段的灯塔，行动的指南
- **定位**：你是谁的决定，选择的基础，进退的根据

**三者的主次：**

先有**定位**（知道自己是谁），才有**目标**（知道自己去哪里），然后才谈得上**责任**（知道自己该承担什么）。但在现实中，往往是先误打误撞承担了责任，在过程中找到目标，最终才锚定定位。

纠结顺序没有意义，**从任何一个起点开始都可以**。关键是：意识到这三个问题是一体的，不能只解决其中一个而忽略另外两个。
