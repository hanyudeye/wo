# 时间分配

## 使用「每日复盘」防止时间消失

```
7月24日

完成：
✓ Python 30分钟

浪费：
刷视频 1.5小时

调整：
晚上关闭短视频App
```

连续记录 30 天，你会明显发现自己的时间黑洞。

## 使用工具

### 简单方案

Google Calendar / 日历：

安排：

* 工作
* 学习
* 运动
* 休息

打开日历即可看到一天结构。

---

### 高级方案（适合你）

你使用 Ubuntu、Emacs、AI 工具，可以：

### Emacs Org-mode

建立：

```
~/org/todo.org
```

例如：

```org
* 今天
** TODO 学习 ChatTTS
SCHEDULED: <2026-07-24 19:00>
** TODO Python
SCHEDULED: <2026-07-24 20:00>
```

每天打开 Emacs：

```text
Agenda
↓
看到今天安排
```

它非常适合长期规划。

## 给自己制造「时间感」

几个有效方法：

### 年度视角

打印：

```
2026剩余天数：

365 - 已过去天数
```

每天减少。

---

### 周视角

每周日：

问：

```
这一周过去后，我距离目标更近了吗？
```

---

### 90天周期

不要规划一年。

规划：

```
未来90天：

目标1：
完成Python基础

目标2：
完成一个AI项目

目标3：
投资系统优化
```

90天更容易产生紧迫感。

---

## 根据你之前提到的情况（下班6点、10点半睡、想学AI/开发、容易被视频分散），我建议采用这个结构：

```
5:00 起床
5:00-6:00 深度学习（最高价值）

白天工作

18:30-19:30 吃饭+休息

19:30-20:30 AI/编程项目

20:30-21:30 娱乐

21:30-22:30 降低刺激，准备睡觉
```

重点不是每天做很多，而是保证：

> 每天至少有一个小时属于未来的自己。

如果没有一个固定系统，时间会自然流向最低阻力的地方。你需要的是一个**每天提醒自己“现在应该把时间给谁”的机制**。
