# 日语学习笔记

> 目标：掌握日常会话核心短语，能进行基本交流

## 学习路线（7 天入门）

### Day 1 — 五十音图 + 问候

- **五十音图** → 先记 あ(a) い(i) う(u) え(e) お(o) / か(ka) き(ki) く(ku) け(ke) こ(ko) / さ(sa) し(shi) す(su) せ(se) そ(so) / た(ta) ち(chi) つ(tsu) て(te) と(to) / な(na) に(ni) ぬ(nu) ね(ne) の(no)
  - 每天背 2 行平假名，边写边读
  - 推荐 app: 多邻国 / 50音起源
- **问候语**（背熟脱口而出）：
  - こんにちは _konnichiwa_ 你好
  - おはようございます _ohayou gozaimasu_ 早上好（正式）
  - おはよう _ohayou_ 早上好（非正式）
  - こんばんは _konbanwa_ 晚上好
  - さようなら _sayounara_ 再见
  - じゃあね _jaa ne_ 回头见
  - またね _mata ne_ 再见（随意）

### Day 2 — 礼貌用语 + 自我介绍

- **礼貌用语**：
  - ありがとう _arigatou_ 谢谢（普通）
  - ありがとうございます _arigatou gozaimasu_ 非常感谢（正式）
  - すみません _sumimasen_ 对不起 / 打扰一下 / 麻烦您
  - ごめんなさい _gomen nasai_ 对不起（口语）
  - どういたしまして _dou itashimashite_ 不客气
  - はい _hai_ 是的
  - いいえ _iie_ 不是
- **自我介绍**：
  - 私は〜です _watashi wa ~ desu_ 我叫〜
  - 〜と申します _~ to moushimasu_ 我叫〜（谦让语）
  - はじめまして _hajimemashite_ 初次见面
  - よろしくお願いします _yoroshiku onegai shimasu_ 请多关照

### Day 3 — 基本提问 + 数字

- **基本提问**：
  - これは何ですか？ _kore wa nan desu ka?_ 这是什么？
  - いくらですか？ _ikura desu ka?_ 多少钱？
  - どこですか？ _doko desu ka?_ 在哪里？
  - 誰ですか？ _dare desu ka?_ 是谁？
  - 何時ですか？ _nanji desu ka?_ 几点了？
  - お名前は何ですか？ _onamae wa nan desu ka?_ 您叫什么名字？
- **数词**（1-10）：
  - いち _ichi_ / に _ni_ / さん _san_ / し/よん _shi/yon_ / ご _go_
  - ろく _roku_ / しち/なな _shichi/nana_ / はち _hachi_ / きゅう _kyuu_ / じゅう _juu_

### Day 4 — 购物 / 用餐

- **购物**：
  - これをください _kore wo kudasai_ 给我这个
  - 安いですね _yasui desu ne_ 好便宜啊
  - サイズはありますか？ _saizu wa arimasu ka?_ 有大小号吗？
  - 見せてください _misete kudasai_ 请给我看看
- **用餐**：
  - いただきます _itadakimasu_ 我开动了
  - ごちそうさまでした _gochisousama deshita_ 谢谢款待
  - メニューを見せてください _menyuu wo misete kudasai_ 请给我菜单
  - お会計お願いします _okaikei onegai shimasu_ 买单

### Day 5 — 日常常用短句

- はい _hai_ 是 / いいえ _iie_ 不是
- 大丈夫です _daijoubu desu_ 没关系 / 没问题
- わかりました _wakarimashita_ 我明白了
- わかりません _wakarimasen_ 我不懂
- ちょっと待ってください _chotto matte kudasai_ 稍等
- お願いします _onegai shimasu_ 拜托了
- いいですね _ii desu ne_ 真好
- そうですか _sou desu ka_ 是这样啊
- できますか？ _dekimasu ka?_ 可以吗？
- だめです _dame desu_ 不行

### Day 6 — 动词基础（ます形）

- 食べます _tabemasu_ 吃 / 飲みます _nomimasu_ 喝
- 行きます _ikimasu_ 去 / 来ます _kimasu_ 来 / 帰ります _kaerimasu_ 回去
- 見ます _mimasu_ 看 / 聞きます _kikimasu_ 听
- 話します _hanashimasu_ 说 / 読みます _yomimasu_ 读 / 書きます _kakimasu_ 写
- 句型：〜を〜ます
  - ご飯を食べます _gohan wo tabemasu_ 吃饭
  - 本を読みます _hon wo yomimasu_ 读书
  - 日本語を話します _nihongo wo hanashimasu_ 说日语

### Day 7 — 综合复习 + 实战

- 把前 6 天的短语全部过一遍
- 模拟场景自问自答（起床 → 出门 → 吃饭 → 购物 → 回家）
- 找日语短视频 shadowing（影子跟读）

## 小技巧

- **すみません** _sumimasen_ 万能词：道歉 / 搭话 / 感谢 都能用
- **大丈夫** _daijoubu_ 万能词：没问题 / 没关系 / 还可以
- 日语动词分三类（五段 / 一段 / サ变・カ变），先记ます形就够了
- 用 Anki 做卡片复习（`日语卡片.md` 已按词性分好可直接用）

## 🐘 实战：用 Mastodon 刷日语信息流

把刷推变成日语练习——在 Spacemacs 里刷 Mastodon 时间线，接触真实日语。

### 设置步骤

```bash
# 1. 克隆社区层
git clone https://github.com/ksonney/spacemacs-mastodon.git ~/.emacs.d/private/mastodon
```

```elisp
;; 2. 在 .spacemacs 的 dotspacemacs-configuration-layers 里加上
mastodon

;; 3. 在 dotspacemacs/user-config 里设置实例
(setq mastodon-instance-url "https://mastodon.social")
```

`SPC f e R` 重载配置。首次启动会提示输入邮箱和密码登录。

(setq mastodon-active-user "hanyudeye")
