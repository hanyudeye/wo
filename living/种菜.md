# 种菜

> 自家几分地的实战记录：虫害处理 + 小型农机具选型。

---

## 地下害虫防治

### 先诊断：地上症状 → 地下凶手

**傍晚或天刚亮**带手电，找一棵倒伏的苗，**从断口往下挖 3-8cm** 看虫。

| 症状 | 凶手 | 特征 |
|---|---|---|
| 茎基部被咬断、**断口整齐**，苗倒在旁边 | 地老虎（地蚕、切根虫） | 夜出土咬断苗并拖回洞里 |
| 苗萎蔫但**没断**，根被咬断，断口整齐 | 蛴螬（金龟子幼虫） | 肥厚乳白"C"形，头褐，8cm 左右 |
| 根部咬成**乱麻状**，地表有隆起隧道 | 蝼蛄 | 地表串成纵横土垄 |
| 茎上小孔，**外皮还连着**（似断非断） | 金针虫 | |
| 叶被啃出小洞、缺刻，苗**没倒** | 菜青虫、小菜蛾、斜纹夜蛾 | 白天藏叶背/心叶 |
| 叶卷起、黏液、大量小虫 | 蚜虫、蓟马 | |
| 雨后夜里叶面被刮食、有亮黏液痕 | 蛞蝓、蜗牛 | 早上见虫和透明黏液 |

"苗从根上齐刷刷倒掉" = 地老虎或蛴螬。

### 立即可做（物理，优先）

1. **罩防虫网**——最有效。40-60 目纱网，四周压实，底边埋土 5cm。**带孔塑料筐等于没罩**。刚种下时这是唯一一劳永逸的措施。
2. **清晨挖虫**——沿断苗一侧深挖 3-8cm 手抓，蛴螬常贴着根。地老虎晚间抓命中率最高。
3. **草把诱集**（专打地老虎）——傍晚把碎莴苣叶/鲜草/泡桐叶堆在行间，压石头防风吹跑。清早翻开捕杀，连做 5-7 天。**用完的草要烧掉或深埋**。
4. **糖醋液诱杀成虫**（地老虎、金龟子）——糖:醋:水 ≈ 3:4:10，浅盆架高离地 30-50cm，傍晚摆出、清早收，隔两天补一次。书上比例含敌百虫，家里**不要加**。
5. **草木灰撒根际**——碱性，驱蛴螬、地老虎并阻止成虫产卵。茄子、番茄、辣椒、芋头等喜酸作物少用。
6. **黄/蓝粘虫板**挂行间，诱蚜虫、蓟马、小菜蛾。
7. **杀虫灯**（太阳能款即可）——金龟子、蝼蛄、地老虎成虫趋光强。关灯是活动高峰，晴朗无风夜效果好。

### 生物源农药（刚种下最合适）

| 药剂 | 对谁有效 | 用法 |
|---|---|---|
| **卵孢白僵菌 / 绿僵菌** | 蛴螬、地老虎幼虫（专一） | 拌湿土，移栽时施入根际，防效 70-90% |
| **苏云金杆菌（Bt）** | 只对**鳞翅目**幼虫：菜青虫、小菜蛾、地老虎 | 低龄幼虫期喷雾，**傍晚喷**，喷后 6h 内别浇水（紫外线杀 Bt）。对蚜虫、蛴螬无效 |
| 苦参碱 / 印楝素 | 蚜虫、蓟马兼杀幼虫 | 植物源，间隔期短 |

土传害虫隐蔽，**生物农药 5-7 天才见效**，别用一次就下结论，同时继续罩网。

另招：散养鸡鸭进菜地啄蛴螬（金龟子幼虫怕被啄），但要控制时间别让它们啃菜叶。

### ⚠️ 网上老配方别照抄

**敌百虫、辛硫磷、甲基异硫磷、乐果油、水胺硫磷**——国内现行农药管理下多数已禁限用。检索到的农业技术资料里很多还在推这些，家园菜地不要用。

确实需要化学药时（夜蛾暴发等）选氯虫苯甲酰胺类或吡虫啉类，**严格按标签剂量，看清叶菜类安全间隔期（通常 7-14 天）**，采收前换一批不喷过药的菜。

## 小型农机具选型

### 先分清：微耕机 ≠ 深翻

- **微耕机是浅耕**，深度只有 **12-15cm**（旋耕标准 12-15，翻耕 15-18）。真深翻 25-30cm 微耕机做不到。
- 但杀蛴螬、地老虎卵，**15cm + 晾晒 5-7 天**就够（农技指引就是这个数）。深到 30cm 是大田增产需求。
- 目标是"晒土杀虫"的话，**翻土只是手段之一**。

### 三类方案

| 方案 | 价格 | 能力 | 适合 |
|---|---|---|---|
| **A. 覆盖免耕**（无机器）| 地膜 1-2 元/㎡ | 不翻土，直接闷死虫卵草籽 | 夏秋休茬期，等得起 1-2 个月 |
| **B. 锂电微耕机** | 200-600 元（出口款）/ 800-1400 元（品牌）| 浅耕 8-15cm，5-10kg | 地小、土松、只求整地 |
| **C. 汽油微耕机 170F** | 1500-2500 元 | 浅耕 15-20cm，幅宽 40-60cm，自走 | 地 ≥200㎡、土硬、一年用 6 次以上 |

**A. 覆盖闷土（最对症）**——不用买机器，而且直接冲着虫卵去：

1. 休茬期**大水灌透**（关键，湿闷才有效，干闷几乎没用）
2. 铺**银黑双色膜**：银面朝上反光降温 + 驱蚜虫，黑面朝下断光杀草
3. 密闭 **15-20 天**。覆膜后地表可达 50-60℃，根结线虫 55℃ 十分钟即死，蛴螬卵、地老虎卵、草籽同样扛不住
4. 揭膜**通风 5-7 天**再定植

缺点：占 1-2 个月地。**不能在青菜还活着的地里做**。

**B. 锂电微耕机**——1688 上的 100-200 元款是出口规格，550W、幅宽 20-25cm、刀片软，硬土一啃就憋火，只适合花盆/育苗盘/已松过的地。认真买 800-1400 元：24V/40V、刀片 65 锰钢、两块可换电池、有正规售后（40V 双电池套装约 1300 元）。好处是无油无噪音、5kg 拎走、塞后备箱。局限：干硬土啃不动，**必须提前 2-3 天浇水**或雨后作业；电池 2-3 年后要换。

**C. 汽油微耕机**——惠农网批发价：两驱 170 汽油皮带款 1599 元、两驱 173 柴油 2299 元、四驱 2560 元；零售宗申套装 1950-2300 元。常见品牌：宗申、隆鑫、富世华、嘉陵、亚特、科农、锄禾。几分地一年用 3-4 次的话，**闲置率和维护成本会吃掉性价比**（汽油机闲置涉及化油器、机油、密封件老化）。

### 买之前必须知道的 4 个坑

1. **不能在已种菜的地里作业**，会绞断根系。
2. **干土不能旋耕**——硬土上机等于用刀片刨石头，憋火、崩刀、烧离合。先浇透水或等雨。
3. **一定要配行走轮**，否则机器自己往前冲，得一直扶着。
4. **刀片要能单独买**，问清售后单卖刀片多少钱一副。

### 不买机器的替代

- **三齿园艺叉 / 弹齿耙**（spading fork）：比钉耙**省力得多**（不压实土、杠杆撬），几十到一百多块，但仍然累。
- **免耕种植**：育苗盘育苗 → 移栽到大块，不整全土。堆肥铺表面 5-8cm 慢慢往下渗。**最省力的长期方案**。
- **秸秆/木屑覆盖**：盖一层保墒、抑草、腐解成有机质，第二年这块地就不用深翻了。

### 建议节奏

1. **菜还活着的时候**：不动土，用上面的物理 + 生物方案处理虫。
2. **收完这一茬**：泥巴**湿**的时候翻耕（比干土省力），然后铺银黑膜闷 15-20 天。
3. **嫌翻耕也累**：等这茬结束买台 800-1400 元锂电微耕机，一年用 4-6 次，比 2000 元汽油机划算，比钉耙省力 5 倍。
4. **稳定到 3 分地以上、连续种几年**再上汽油 170F。
