# 素食 · 橱柜与营养

> 一张不依赖任何书的实用卡。目标是：**橱柜里有这几样东西，就能不额外采购地凑出一顿完整饭**。
> 核心原则：**先建橱柜，再谈菜谱。** 菜谱是无限的，橱柜是有限的。

---

## 一、橱柜清单

### 蛋白（最关键，缺了就只是一碗碳水）

| 类别     | 具体                                            |
|----------|-------------------------------------------------|
| 豆类罐头 | 鹰嘴豆、黑豆、混合豆、番茄豆（去皮番茄 + 黑豆） |
| 鲜豆制品 | 老豆腐、豆干、油豆腐、腐竹                      |
| 干豆     | 黄豆、黑豆、红豆、扁豆（鹰嘴豆）                |
| 豆制品粉 | 鹰嘴豆粉意面、扁豆粉意面                        |
| 其他     | 素鸡/素肉（国内已能买到本土植物肉）             |

> **大豆是完全蛋白**（含全部必需氨基酸）——纯素饮食里唯一不用担心的宏量营养素就是蛋白。

### 主食替代

糙米、藜麦、燕麦、粉丝/米粉、意面、玉米、馒头/面饼

### 增味（纯素厨房的命门）

| 东西                   | 干什么用                                     |
|------------------------|----------------------------------------------|
| **味噌**               | 万能增鲜，一勺解决寡淡                       |
| **香菇粉**             | 代替鸡精，鲜味天花板                         |
| **酵母粉**（营养酵母） | 代替奶酪和帕玛森，拌面拌饭都能救             |
| **芝麻酱 / 花生酱**    | 提供"油感"和饱腹感，纯素餐最容易缺的就是这个 |
| 柠檬汁 + 酵母粉        | 简易奶酪（沥水 30 分钟）                     |
| 味精                   | 纯素 OK（发酵来的），别被"化学"两个字吓到    |

### 奶替代

豆浆、燕麦奶、椰浆（国内现在很便宜）、杏仁奶

### 冷冻区（性价比最高的一格）

豌豆、玉米、西兰花、胡萝卜丝、混合蔬菜、整颗番茄

**冷冻蔬菜比鲜的便宜，而且不浪费**——烂掉的鲜菜才是真浪费。

### 干料

海带、紫菜、木耳、香菇（干）、红枣、坚果、亚麻籽/奇亚籽

## 二、凑饭公式（不用记菜谱）

> **蛋白基底 + 蔬菜 + 主食 + 酱汁**

| 蛋白基底         | 蔬菜          | 主食      | 酱汁                  |
|------------------|---------------|-----------|-----------------------|
| 鹰嘴豆           | 冷冻杂蔬      | 糙米/米饭 | 番茄 + 洋葱 + 蒜 炒酱 |
| 老豆腐           | 菠菜/白菜     | 米饭      | 味噌 + 一点点芝麻酱   |
| 腐竹             | 木耳 + 青椒   | 面条      | 芝麻酱 + 醋 + 蒜      |
| 扁豆意面         | 番茄          | 意面      | 蒜 + 辣椒 + 橄榄油    |
| 豆浆             | 香蕉          | 燕麦      | 花生酱（早上一分钟）  |
| 干豆（前一晚泡） | 胡萝卜 + 土豆 | 任意      | 咖喱粉 + 椰浆         |

**先做一次大锅**：周末煮一锅豆子或米饭，分装冷冻。这是所有"快手素食"的地基。

## 三、营养缺口表

| 营养素       | 为什么会缺                     | 怎么补                                                                   |
|--------------|--------------------------------|--------------------------------------------------------------------------|
| **B12**      | 植物性食物里**完全没有**       | ⚠️ **唯一必须补充的**，没有例外。合成片或强化食品，定时吃                 |
| **铁**       | 植物铁吸收率只有 2-20%         | 豆类/菠菜**和维 C 同吃**（彩椒、西兰花、柠檬）；**避开**茶、咖啡、钙同餐 |
| **Ω-3**     | 坚果种子只有 ALA，缺 EPA/DHA   | 亚麻籽、奇亚籽、核桃 + 直接吃**藻油**                                    |
| **碘**       | 植物性食物极少                 | 用**加碘盐**（注意别买成非加碘盐）；海带紫菜                             |
| **钙**       | 深绿叶菜草酸高，吸收差         | 石膏豆腐、芝麻酱、深绿叶菜、钙强化豆奶                                   |
| **维生素 D** | 日照不足就缺（不只是纯素问题） | 晒太阳 + 强化食品。国内人普遍不足                                        |

**关键一条**：一顿饭吃不出饱腹感，通常是**缺脂肪或缺纤维**，不是缺蛋白。加芝麻酱、坚果、完整谷物就能解决。

## 四、中式调味料的纯素陷阱

> 这张表比任何素食菜谱都更实用。**买之前先看配料表。**

| 调料               | 状态                                                |
|--------------------|-----------------------------------------------------|
| 蚝油               | ❌ 含牡蛎                                           |
| 鸡精 / 鸡粉        | ❌ 含鸡肉                                           |
| 鱼露               | ❌ 含鱼                                             |
| 沙茶酱             | ❌ 常含虾米                                         |
| 沙拉酱 / 千岛酱    | ❌ 常含蛋黄                                         |
| 吉利丁             | ❌ 动物源（烘焙用**琼脂/寒天**代替）                |
| 黄油 / 猪油 / 牛油 | ❌                                                  |
| 咖喱块             | ❌ 常含动物脂肪和奶（用**咖喱粉**代替）             |
| 豆瓣酱             | ⚠️ 正牌是纯素（黄豆/蚕豆），但有加猪油的，**看配料** |
| 生抽 / 老抽        | ⚠️ 一般含小麦（纯素没问题，**无麸质**需求者要注意）  |
| 味精               | ✅ 纯素 OK                                          |
| 甜面酱             | ✅ 一般纯素                                         |

## 五、几个容易踩的坑

1. **别把纯素道德化**。健康和长寿的目标，不吃荤也能达成（地中海式、素食证据充分）。长期依从率上，**弹性饮食（一周吃几次素）比严格纯素高得多**。
2. **B12 是唯一"没有食物能解决"的营养素**。这条没得商量。
3. **冷冻蔬菜不代表营养差**。采摘后往往比放了三天的新鲜菜营养还高。
4. **豆腐买当周吃完**。豆制品保质期短，别一次囤。
5. **开罐的豆类一次用完**。开过罐的鹰嘴豆质地变差，也不好存。
6. **干豆提前一晚泡**。泡豆这一步是"快手"的必要条件，别指望现做。

## 六、省钱要点

- 干豆 + 大批量烹煮分装冷冻：**一次做饭，吃一周**
- 冷冻蔬菜 > 临期鲜菜 > 正常价鲜菜
- 大包装坚果和种子（坚果容易氧化，买一次吃一个月内的量）
- 干香料（咖喱粉、孜然、五香粉）保质期长，别买小包
- 味噌、酱油、酵母粉按月补货

## 出处

从 *Quick and Easy Vegan Meals: With Foods You Already Have in Your House*（Elizabeth Cooke，EEEnt，2023）的讨论里拆出来的实用部分。**那张书没解决的核心问题是"中式厨房没有西式素食橱柜"，所以本卡的清单和营养表是重写的，不是书摘。**

原书的三个已知问题：前提依赖西式 pantry（canned beans / coconut milk / tahini）；"用现有的"是稀缺策略不是健康策略；**很可能通篇不提 B12**。
