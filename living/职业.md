# 我喜欢科技，但不是从事这个行业，如何自学，学哪些学科，可以往这个职业方向靠拢，我现在对人工智能感兴趣，推荐我职业方向和学科书籍或如何入学

可以，而且我认为你**不应该把目标定成“自学 AI，最后成为 AI 科学家”**。对于你这种“本来喜欢科技、已经有一些编程兴趣、但目前不是 IT 从业者”的情况，更现实的路线是：

> **先成为一个能用 Python + AI 构建实际产品的人 → 再根据兴趣向 AI 应用开发、AI Agent、数据/自动化、机器学习工程等方向分化。**

这条路线比直接啃高等数学、论文、深度学习理论有效得多。

## 一、先判断：你适合进入什么职业方向

我把 AI 相关职业大致分成 5 层：

| 方向                |   数学要求 |   编程要求 |   入行难度 | 我对你的建议     |
|---------------------|-----------:|-----------:|-----------:|------------------|
| AI 工具/自动化      |         ★ |       ★★ |       ★★ | **很适合起步**   |
| AI 应用开发         |       ★★ |     ★★★ |     ★★★ | **最推荐**       |
| AI Agent / LLM 应用 |       ★★ |   ★★★★ |     ★★★ | **重点方向**     |
| 机器学习工程师      |   ★★★★ |   ★★★★ |   ★★★★ | 后期再考虑       |
| AI 算法/研究        | ★★★★★ | ★★★★★ | ★★★★★ | 暂时不要作为目标 |


我尤其推荐你考虑：

### ① AI 应用开发者

不是研究怎么训练 GPT，而是：

> **利用现有模型，把 AI 做成真正能工作的软件。**

例如：

* AI 记账
* AI 翻译工具
* AI 阅读助手
* AI 新闻摘要
* AI 知识库
* AI 客服
* AI Agent
* AI 自动化工作流
* AI 内容生成系统
* 本地 AI 工具
* RAG 知识库
* AI + 浏览器自动化

这类工作对学历和数学的要求，相比 AI 算法研究低很多。

而且你之前已经想到过**做个人记账工具**，这个其实非常适合作为你的第一个长期项目。

# 三、第二阶段：计算机基础

这是很多 AI 初学者忽略的东西。

你最终想进入科技行业，真正应该建立的是：

### CS 基础

学习：

* Linux
* Git
* Shell
* 网络
* HTTP
* API
* 数据库
* SQL
* 数据结构
* 算法
* 软件工程

不用一开始就把《算法导论》啃下来。

你的目标是达到：

> **看到一个技术问题，知道它属于什么领域，并且知道去哪里解决。**

这比背算法重要。

# 四、第三阶段：数学

数学要学，但**不要先学数学再学 AI**。

这是很多人最容易走错的路。

推荐：

### 线性代数

重点：

* 向量
* 矩阵
* 矩阵乘法
* 转置
* 特征值/特征向量
* 线性变换
* 向量空间

因为神经网络本质上大量进行矩阵运算。

### 概率统计

重点：

* 概率
* 条件概率
* 贝叶斯
* 随机变量
* 期望
* 方差
* 概率分布
* 最大似然

### 微积分

重点：

* 导数
* 偏导数
* 梯度
* 链式法则
* 梯度下降

你不需要一开始达到数学系水平。

# 2. 最关键的是“抓手”

如果你说的“抓手”是指**机械抓手**，我非常建议加入。

但不要一开始做 6 自由度机械臂。

第一代只需要：

> **一个旋转关节 + 一个上下关节 + 一个夹爪**

例如：

```text
        摄像头
          │
       ┌──┴──┐
       │ Head│
       └──┬──┘
          │
        Servo
          │
       ───┴───
          │
        Arm
          │
        Servo
          │
        ┌─┴─┐
        │夹爪│
        └───┘
```

它可以完成：

* 拿笔
* 推按钮
* 拿小物件
* 指向东西
* 把东西移动到另一个位置

**机械执行能力会让 AI Agent 突然变得非常有意思。**

# 3. 大脑不要放在机器人里面

这是非常重要的设计。

> “我需要一个很强的机器人电脑。”

```text
机器人
   │
   ├── 麦克风
   ├── 摄像头
   ├── 舵机
   ├── 扬声器
   │
   ↓

   │
   ↓
你的 Mac / Windows
   │
   ├── LLM
   ├── Speech-to-Text
   ├── Text-to-Speech
   ├── Agent
   └── Vision
```

这样成本和复杂度会大幅下降。

甚至：

> **机器人本体只负责传感器和执行器。**

```text
调用 arm.move()
 ↓
调用 gripper.close()
 ↓
机械臂执行
 ↓
“我拿到了。”
```

这才是真正的 Agent。

# 5. Agent 本身其实不复杂

你可以把它理解成一个 Python 程序：

```text
Agent
│
├── memory()
│
├── listen()
│
├── think()
│
├── see()
│
├── speak()
│
└── tools
     ├── move_arm()
     ├── open_gripper()
     ├── close_gripper()
     ├── look()
     ├── search()
     └── timer()
```

LLM 的核心任务不是直接控制电机。

而是：

> **决定什么时候调用什么工具。**

例如：

```text
User:
“把笔拿给我”

LLM:
需要视觉 → camera()

camera:
笔在 x=320,y=210

LLM:
调用 move_arm(320,210)

机械臂:
执行

LLM:
调用 close_gripper()

机械臂:
夹住

LLM:
“拿到了。”
```

# 6. 你的第一个版本甚至不用机械臂

我建议你分 **4 个版本**做。

### V0：纯软件 Agent

先在电脑上实现：

```text
语音输入
 ↓
LLM
 ↓
工具调用
 ↓
语音回答
```

工具只有：

```text
time()
weather()
search()
calculator()
notes()
```

这个阶段学习 Agent 架构。

---

### V1：加一个“头”

买：

* Raspberry Pi / 类似 SBC
* USB 麦克风
* 小扬声器
* 摄像头
* 2～3 个舵机

让它能够：

> 转头 + 说话 + 看你。

这已经很有“机器人感”。

---

### V2：加抓手

再加入：

> 2～4 自由度机械臂 + 夹爪。

此时：

> AI → Python → Servo

整个控制链跑通。

---

### V3：真正的智能体

增加：

**视觉 + 长期记忆 + 工具调用 + 任务规划**

例如：

> “每天晚上 8 点提醒我学习。”

Agent 可以：

```text
创建定时任务
        ↓
8:00 PM
        ↓
机器人转向你
        ↓
“该学习了。”
```

甚至：

> “陪我学习 Python。”

然后它可以：

* 记录学习时间
* 给你出题
* 解释代码
* 记录进度
* 定时提醒
* 根据你的学习历史调整难度

这就开始成为一个真正的**个人 AI Agent**。
