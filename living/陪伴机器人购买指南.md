# 陪伴机器人·购买与 DIY 指南

> 场景:**代替小狗 / 简单的单身陪伴**(会缓慢走动、可 AI 对话、最好有视觉识别,玩具尺寸 20–40cm)。
> 结论速览:买现成首选 **Loona**;想折腾可 **Petoi Bittle DIY**;只要对话陪伴,国产百元档就够。

---

## 需求三要素(核对清单)

- [ ] 像小狗 / 小动物,尺寸 20–40cm,玩具大小
- [ ] 能缓慢走动
- [ ] 接入大模型,可自然对话(中文)
- [ ] 最好有视觉识别(认人、避障)
- [ ] 简单、好用、真陪伴感,而不是“会动的小玩偶”

**关键认知**:市面上“真·会走路 + 真·AI 对话 + 真·摄像头视觉”三者齐、又到了玩具尺寸的量产品,目前基本只有 Loona;几百块的便宜机器狗多是预设动作无真对话;几千上万的宇树/大疆偏开发平台。

---

## 方案 A:买现成

| 方案 | 价格(约) | 会走 | AI 对话 | 视觉 | 备注 |
|---|---|---|---|---|---|
| **Loona Petbot**(宙物/KEYi) | ¥2500–4000 | ✅ 四足慢走/跳舞 | ✅ 接入 GPT,中文流畅 | ✅ 人脸识别+避障+跟随 | **首选**,屏幕当眼睛,会认主人,有性格 |
| 华为「智能憨憨」 | ¥399 | ❌ 毛绒不动 | ✅ 小艺大模型+日记记忆 | ❌ | 能撸、能倾诉、记住悄悄话,性价比高 |
| 京东京造 AI 毛绒玩具 | ¥100+ | ❌ | ✅ 基础对话 | ❌ | 入门试水 |

### Loona 要点

- 20cm 级,四足可缓慢走动、跳舞;屏幕做“眼睛”可眼神交流
- 2026 版接入 GPT,实时多语言对话(含中文),确认免订阅
- 自带摄像头 + 3D 传感器:人脸识别、识别主人、避障、跟随,可当移动监控
- 购买注意:询问是否需要云端订阅、中文支持、摄像头隐私策略

## 方案 B:DIY 自组(技术流)

适合会 Linux / 脚本的人,成本与 Loona 相仿,可控但费时(约 1–2 个月业余时间)。

### 硬件(约 ¥1500–2500)

- 底盘:**Petoi Bittle**(约 $229–279),四足开源狗,Arduino + 树莓派/兼容板
- 语音输入:USB 麦克风(或 ReSpeaker 阵列)
- 视觉:树莓派 Camera Module + MediaPipe / OpenCV 人脸识别
- 扬声器:USB 音箱

### 软件(全免费)

- 对话大脑:本地 Ollama(装 Qwen / DeepSeek 蒸馏版)或 API(DeepSeek / 豆包 / Kimi,中文便宜)
- 语音转文字:Whisper(`faster-whisper`)
- 文字转语音:`edge-tts`(微软免费语音,中文自然)
- 主控:Python 状态机 = 待机(摇尾巴动议案)→ 被叫名字 → 对话 → 跟随

### 陪伴感的关键:system prompt

给 LLM 一段“狗设”:

> 你是一只 3 岁的小狗,叫我主人。喜欢听我讲今天发生的事,会给我安慰和鼓励,偶尔撒娇。语气温暖、简短,像小狗一样不会太长篇大论。

---

## 决策建议

- 图省心、要真“小狗感”会动 → 直接买 **Loona**
- 想折腾、要完全自己掌控(可长期迭代玩法)→ **Petoi Bittle + API + Whisper + edge-tts** 按上面配置搭
- 预算敏感、可接受“不会动” → 华为智能憨憨(¥399)先体验

---

## 避坑提醒

- 百元档“AI 机器狗”多为预设动作 + 假对话,别被“大模型”宣传带偏
- 云端对话产品注意:订阅费、联网要求、隐私(摄像头在室内一直开着)
- 行业普遍“数据水分大”,价格与功能差异远超宣传文案
- 陪伴类不以“功能多”取胜,以“情感连贯 + 记忆 + 稳定”为真标准
