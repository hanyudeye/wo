# 饮食健康

## 牛奶与免疫力

牛奶对免疫有帮助：优质蛋白（抗体原料）、锌/硒、维 D（强化奶）、乳酸菌（酸奶/开菲尔）。

但别神话它：
- 免疫是系统工程，不靠单一食物
- 蛋白质已够则多喝无额外收益
- 熬夜/久坐/压力大都补不回来

**提升免疫力更有效（按优先级）：**
1. 睡够 7h
2. 每天晒 15min 太阳（维 D）或补剂
3. 蛋白质吃够（蛋/奶/肉/豆）
4. 益生菌 + 膳食纤维（肠道健康）
5. 适度运动

## 久坐办公人群饮食建议

**牛奶：可以喝，但非必须**
- 好处：补钙防骨质疏松（久坐+少晒太阳容易缺钙）、优质蛋白
- 注意：乳糖不耐选酸奶/舒化奶

**久坐人重点摄入：**

| 需求 | 吃什么 |
|------|--------|
| 护眼（盯屏幕） | 蓝紫色食物（蓝莓/紫甘蓝/枸杞）、深色绿叶菜、胡萝卜 |
| | 替代方案：叶黄素酯软糖/胶囊、蓝莓干/枸杞干、冻干绿叶菜粉、南瓜/红薯、鸡蛋（蛋黄）、玉米 |
| | 技巧：冷冻菠菜直接丢汤/粥/面，或破壁机+香蕉+牛奶打成 smoothie |
| 抗炎（久坐慢性炎症） | 坚果/鱼油/橄榄油、姜黄、绿茶 |
| 防便秘（久坐肠胃蠕动差） | 燕麦/奇亚籽/亚麻籽、西梅、每天 2L 水 |
| 稳定精力（防饭后困） | 低碳水早餐（蛋/希腊酸奶）、少吃精制碳水 |
| 腰椎/骨骼 | 奶制品/豆制品/绿叶菜（钙）、维生素 D（晒太阳或补剂） |

**总结：** 每天一杯奶 + 一把坚果 + 一斤蔬菜 + 2L 水，少精制碳水，比纠结单一食物重要得多。

## 空气炸锅

### 对比
- 空气炸锅 vs 微波炉：微波炉加热快但烤不出脆皮，空气炸锅外酥里嫩、干净卫生（无汤汁飞溅）。偶尔烤点东西，空气炸锅体验好很多，200-400 元即可
- 空气炸锅 vs 烤箱：空气炸锅预热快（2-3min vs 5-10min）、占地小、省电、好洗。烤箱优势：容量大、温度均匀、适合烘焙。**独居/小家庭选空气炸锅更实用**
- **并不比烤箱耗电**：腔体小、加热快，一次炸鸡翅约 0.2-0.3 度电

### 省电技巧
1. 提前解冻到室温
2. 切小块/薄片，表面积大传热快
3. 食材擦干水分，减少蒸发耗能
4. 一次塞满（不重叠），别开两次
5. 提前 1 分钟关掉，用余热收尾
6. 多数食材不需要预热

### 适合烤的素菜（少油/无油）

| 食材 | 处理 | 温度/时间 | 口感 |
|------|------|-----------|------|
| 花椰菜/西兰花 | 切小朵，喷油+盐+黑胡椒 | 180°C 10min | 边缘焦脆像烧烤 |
| 杏鲍菇/金针菇 | 撕条，少油+烧烤料 | 180°C 8-10min | 口感像肉 |
| 红薯/南瓜 | 切厚片/条 | 180°C 15min | 外焦里糯 |
| 老豆腐 | 切块，少油+酱油+辣椒粉 | 180°C 12-15min | 外酥里嫩 |
| 秋葵/芦笋 | 整根少油撒盐 | 180°C 6-8min | 脆甜 |
| 土豆 | 切块泡水去淀粉，沥干+少油+迷迭香 | 180°C 15min | 比薯条健康 |
| 口蘑 | 去柄倒扣 | 180°C 8min | 中间一汪鲜汤 |
