# 副业思路：自卑、胆小、懦弱的人怎么发财

关键：不要把"现在的我"当成"永远的我"。能发财的性格和"强势/外向/胆子大"几乎没有关系。

## 适合内向/社恐/谨慎型性格的路径

- **线上/技能型路径** — 编程、设计、写作、做工具型产品，不需要面对面销售，不需要喝酒应酬，坐在电脑前解决问题即可。自卑还是自信，代码跑得动就行。
- **低社交杠杆** — 做内容（公众号/视频/播客）、做自动化产品（SaaS/模板/知识付费），一次产出被反复售卖，不需要每次去谈。
- **谨慎本身就是优势** — 胆小意味着不太可能一把梭哈、不会贸然踩坑、更可能做风险控制。很多人发财之前不是穷死的，是作死的。

问题不是"我这种性格怎么发财"，而是**"我愿不愿意找一个跟性格匹配的赛道"**。

自卑和懦弱往往来源于**你从来没在一件事上持续做到过自己认可的水平**。选一件小事，坚持下去，用结果给自己正反馈，比先"改变性格"再行动要靠谱得多。

## 技能型工作去哪找

找不到，是因为在用找**"工作"**的方式在找，技能型路径大多不以**"岗位招聘"**的形式存在。

### 1. 自由职业平台（低门槛、马上能接单）
- 国内：猪八戒、一品威客、闲鱼（搜"代做PPT/代写/修图"）
- 国外：Upwork、Fiverr（英文要求不高，翻译工具就行）
- 单子类型：Excel代做、PPT美化、视频剪辑、翻译、LOGO设计、爬虫脚本

### 2. 电商型技能（不需要找工作，直接卖）
- 淘宝/闲鱼/拼多多卖服务，搜"代做"看品类：简历修改、论文排版、CAD出图、PPT美化

### 3. 内容/产品型技能（一次产出，长期卖）
- 做 Notion/AI 模板、Obsidian 主题、PPT 模板 — 小红书/知乎/B站搜索"副业 模板"
- 写 Python 脚本/自动化工具，GitHub 开源，接付费咨询

### 4. 社区/社群里的隐形需求
- 加副业微信群、自由职业群，看别人每天花钱求什么。90%的需求不上招聘网站。

### 马上就能做的一件事
打开闲鱼/小红书，搜"代做"，看排在前面的服务是什么 — 那就是普通人当下能赚钱的技能。
