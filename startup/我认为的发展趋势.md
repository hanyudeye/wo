如何做一个小机器人伙伴

按照你的目标（桌面、小巧、像木偶人、有陪伴感、能学习/运动提醒/聊天），不要一开始做复杂机器人。最现实的路线是：

**先做一个“有身体的 AI 伙伴”，再逐步增加动作能力。**

完整结构：

```
            AI大脑
              |
    --------------------
    |                  |
  语音系统          记忆系统
    |                  |
麦克风/扬声器       数据库
    |
 机器人身体
    |
屏幕眼睛 + 舵机 + 外壳
```

---

## 第一阶段：桌面 AI 人偶（最推荐）

目标：

* 放桌面
* 会说话
* 有表情
* 记得你的习惯
* 提醒学习、运动

成本：
约 500～1500 元

### 硬件

### 1. 主控

推荐：

**Raspberry Pi 5**

作用：

运行 Python 程序、连接 AI。

或者：

你已有电脑 + 一个小开发板也可以。

---

### 2. 屏幕（最重要）

不要先做复杂机械。

一个“小脸”比机械动作更有陪伴感。

例如：

* 1.5～2.8寸 OLED/LCD

显示：

```
( ^_^ )
今天学习了吗？
```

眼睛动画：

* 开心
* 困
* 思考
* 惊讶

人的大脑非常容易对眼睛产生情感反应。

---

### 3. 麦克风 + 音箱

实现：

你说：

> “我要学习Python”

机器人：

> “今天继续做记账软件项目吗？”

硬件：

* USB麦克风
* 小喇叭

---

### 4. 外壳

可以买：

* 3D打印人偶外壳
* 木偶风格外壳
* 小机器人外壳

甚至可以：

买一个便宜玩偶，改装内部。

---

# 第二阶段：增加动作

加入：

## 舵机（Servo）

让它：

* 点头
* 摇头
* 挥手
* 转头

例如：

```
       O  ← OLED眼睛
      /|\
     / |
    舵机
```

需要：

* ESP32
* SG90/MG90S舵机

成本几十元。

---

# 第三阶段：AI大脑

软件结构：

## 语音输入

你的声音：

↓

Whisper

↓

文字

## AI对话

↓

ChatGPT API

或者：

你电脑上的：

Ollama + 本地模型

## 语音输出

↓

Piper TTS

↓

机器人讲话

---

# 第四阶段：加入“伙伴人格”

这是最重要的部分。

不要只是聊天机器人。

建立一个人格文件：

例如：

```
名字：小木
性格：
- 温和
- 鼓励行动
- 不废话

主人目标：
- 学Python
- 健身
- 英语学习

每天：
早上提醒计划
晚上总结
```

AI读取这个长期记忆。

它才像伙伴。

---

# 第五阶段：连接你的生活

可以连接：

### 学习

读取：

* Todo
* Anki
* 日历

提醒：

“今天英语20分钟完成了吗？”

### 运动

连接：

* 手机运动数据
* 手环API

提醒：

“坐太久了，起来活动一下。”

### 家庭

连接：

* Home Assistant

控制：

* 灯
* 空调
* 摄像头
