# 找客户渠道清单

先分“卖给谁”，平台完全不同。核心：**高客单靠信任，低客单靠流量，海外靠 SEO / 自由职业平台**。

## 一、企业客户（B2B：私有化部署 / AI 交付，客单价高）

靠信任，不靠平台流量。

- 熟人圈：前同事、校友、行业微信群、老乡会 —— 转介绍成本最低
- 脉脉、LinkedIn —— 直接找决策人（CTO、信息化负责人、老板）
- 企查查 / 天眼查 —— 按行业、规模筛目标公司，主动 cold outreach
- 行业协会、商会、展会、沙龙、孵化器 / 园区 —— 高客单几乎都来自线下
- 云厂商生态：阿里云 / 腾讯云 / 华为云的市场与服务商计划
- SaaS 厂商渠道：做 Dify、FastGPT、n8n 的实施伙伴 / 代理商
- 内容获客：知乎、公众号、视频号发真实案例，让客户来搜你

免费/低门槛接单平台（拼价格）：猪八戒、一品威客、程序员客栈、猿急送、码市、开源众包。

## 二、中小企业老板（本地服务 / 教培 / 外贸 / 美业）

- 抖音、视频号、快手 —— 本地商家最活跃
- 小红书 —— 教培、美业、女性创业者
- 微信群、行业社群
- 美团 / 大众点评、百度地图、58 同城 —— 导出商家名单做地推
- 线下扫街：批发市场、商圈、行业展会

## 三、海外客户（出海套壳 / SaaS / 自由职业）

- 接单：Upwork、Fiverr、Freelancer、Toptal
- 人脉：LinkedIn、X/Twitter（build in public）
- 社区：Reddit、Indie Hackers、Hacker News、Discord / Slack 群
- 发布产品：Product Hunt、AppSumo（终身交易）
- 长期：SEO + 博客 / YouTube 内容
- 付费：Google Ads、Meta Ads

## 四、开发者 / 技术客户

- GitHub（issue、discussion、赞助）、V2EX、掘金、SegmentFault
- 即刻、少数派、Telegram / Discord 技术群

## 选择原则

- **高客单 B2B**：人脉 + 行业活动 + 内容背书，平台只是辅助
- **低客单 / 本地**：抖音 / 小红书 / 地推名单
- **海外**：Upwork 起步，长期靠 SEO 和 build in public
- 先有案例和作品集（GitHub demo、客户评价），否则任何平台都难转化
- 转介绍永远是最便宜的渠道
