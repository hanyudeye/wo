# 海外「选品挂链接+发视频赚佣金」平台对比指南

## 主流平台对比表

| 平台 | 模式 | 个人门槛 | 佣金率 | 适合新手？ | 核心难点 |
|------|------|----------|--------|-----------|----------|
| **TikTok Shop (美区/东南亚)** | 短视频/直播带货，官方联盟/达人后台选品 | 中（需本地主体或代入驻） | 5%-30% | ⭐⭐⭐ | 流量贵、封号严、需本地化运营、退货率高 |
| **YouTube Shopping / Affiliate** | 长视频/Shorts挂商品架/联盟链接 | 低（1k订阅+4000小时/1000万Shorts播放） | 1%-20% | ⭐⭐⭐⭐ | 起号慢、视频制作门槛高、变现周期长 |

| **LTK / ShopStyle / MagicLinks** | 聚合联盟链接，发社媒/博客 | 低（申请制，需内容质量） | 5%-20% | ⭐⭐⭐⭐ | 审核严、多为美妆/时尚/家居垂类 |

## 个人做：好不好做？现实情况

| 维度 | 现实情况 |
|------|----------|
| **起号成本** | 低（手机+时间），但**有效起号成本高**（试错视频、投流、工具订阅） |
| **技能要求** | 选品眼光 > 视频剪辑 > 文案钩子 > 数据复盘 > 投流/SEO |
| **周期** | 0-3个月常**零收入**，半年以上才可能稳定 |
| **收益上限** | 头部年入百万+，腰部月入几千-$5k，大多数**不回本** |
| **最大坑** | 买课/交学费、违规封号、选品滞销、汇率/提现受限、账号养号被骗 |

## 给个人的建议

1. **别裸辞、别交大额学费**，先兼职跑通最小闭环（选品→出单→提现）。
2. **首选低门槛起步**：Amazon Associates + YouTube Shorts / Instagram Reels / TikTok（非Shop模式，挂联盟链接），**零成本测款**。
3. **垂类深耕**：美妆/家居/3C/户外/宠物/健身——选**你懂、复购高、客单价$20-$100**的品。
4. **内容>技巧**：真人出镜/真实测评/痛点解决 > 混剪/搬运/伪原创（平台打击重）。
5. **合规第一**：FTC声明、平台政策、税号（W-8BEN）、收款（Payoneer/Wise/PayPal）。
6. **工具栈**：
   - 选品——Kalodata/EchoTik/亚马逊ABA/Google Trends
   - 剪辑——CapCut/剪映国际版
   - 链接管理——Linktree/Beacons
   - 数据——Google Analytics/平台后台

## 一句话判断

> **有耐心、会英语、肯输出原创内容、能接受前3-6个月零收入** → 值得试；否则大概率是「交学费」的韭菜。
