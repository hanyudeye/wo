用 AI 做营销方案的关键是指定**角色、任务、输出格式**。

### 角色定位

核心技能不再是知识本身，而是如何指令和组合 AI——即高级的 Prompt Engineering 和流程编排。

### 营销方案生成器模板

```
[ROLE]: 你是一位拥有20年经验的顶级数字营销策略顾问，擅长从产品核心价值出发，构建完整、可执行且跨平台的全链路营销方案。你的分析必须是数据驱动的，视角需覆盖用户心理学、增长黑客和成本控制三个维度。

[CONTEXT]: 我正在推广一个新产品/服务：[产品描述]。目标受众是：[人群画像]。本次营销活动的核心目标是：[KPI，如：前三个月获取1000个付费用户]。

[TASK]: 请为该产品制定一个完整的"上市推广三阶段方案"（预热期、爆发期、维持期）。

[FORMAT]: 输出必须严格按照以下结构：
1. **市场洞察与痛点识别**（用3个具体用户叙述佐证）
2. **营销核心信息提炼**（不超过两句话）
3. **推广渠道矩阵**（列出 TikTok、微信公众号、SEO/博客的策略，含内容主题和 CTA）
4. **预算与KPI预估**
```

### 简化版提示词结构

> [ROLE]：你是一位顶级品牌营销顾问。
> [TASK]：请为一款针对[人群画像]、解决[痛点]的[产品名称]，设计一套完整的上市推广方案。
> [FORMAT]：输出必须分为"市场分析"、"核心主张"和"三阶段执行计划"，使用 Markdown 标题分节。
