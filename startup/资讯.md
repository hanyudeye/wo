## 我希望看到 重要的资讯，但不想被 无关的广告信息吸引注意力，并且能看到资讯上面的联系信息，我该如何得到这个产品

用 **Spacemacs + elfeed 层**，终端内完成订阅→阅读→笔记全流程，无需打开浏览器。

### 安装

在 `~/.spacemacs` 的 `dotspacemacs-configuration-layers` 中添加：

```elisp
(elfeed :variables
        elfeed-enable-elfeed-org t
        elfeed-feeds-file "~/org/feeds.org")
```

`feeds.org` 内按标题层级组织订阅源：

```org
* 技术  :elfeed:
** https://blog.example.com/rss
** https://news.ycombinator.com/rss
* 商业
** https://36kr.com/feed
```

> 注意： 文件 必须带 :elfeed: 标签
   '(elfeed-feeds
     '("https://news.ycombinator.com/rss" "https://blog.devtang.com/atom.xml" "http://feeds.feedburner.com/ruanyifeng" "https://www.ruanyifeng.com/blog/atom.xml"))


### 阅读流程

| 按键 | 功能 |
|------|------|
| `SPC a e` | 打开 elfeed 文章列表 |
| `n` / `p` | 上下移动 |
| `RET` | 内嵌阅读（shr 渲染） |
| `b` | 在外部浏览器打开原文 |
| `S` | 加星收藏 |
| `s` | 按关键字/源/标签搜索 |
| `g` | 刷新/抓取新文章 |
| `q` | 退出 |

**联系方式可见**：内嵌阅读时，文章头部自动显示作者、日期、来源链接。如需查看更多元数据，`b` 跳到浏览器原文，保留原始联系信息。

### 离线阅读

elfeed 自动缓存文章到 `~/.elfeed/`。断网后 `SPC a e` 仍可浏览已缓存文章。

### 进阶玩法

- **elfeed-score**：根据关键词/来源/时间自动打分排序，优质内容靠前
- **elfeed-web**：`M-x elfeed-web` 在本地起 HTTP 服务（端口 8080），手机局域网内可访问
- **org-capture**：Spacemacs elfeed 层默认支持 `C-c c` 捕获文章到 org 笔记

### 自定义标签显示（unread → UR）

Elfeed 的 `unread` 标签是硬编码符号，不能直接改名。需要覆写 `elfeed-search-print-entry-function` 来替换显示文本。

在 `~/.spacemacs` 的 `dotspacemacs-user-config` 中添加：

```elisp
(defun my/elfeed-search-print-entry (entry)
  "自定义 elfeed 搜索条目显示，将 unread 标签显示为 UR。"
  (let* ((title (or (elfeed-entry-title entry) ""))
         (tags (mapcar (lambda (tag)
                         (if (eq tag 'unread) "UR" (symbol-name tag)))
                       (elfeed-entry-tags entry)))
         (tags-str (when tags
                     (propertize (mapconcat #'identity tags ",")
                                 'face 'elfeed-search-tag-face)))
         (feed (elfeed-entry-feed entry))
         (feed-title (when feed (elfeed-feed-title feed)))
         (date (format-time-string "%m-%d" (elfeed-entry-date entry)))
         (title-width (- (window-width) 16)))
    (insert (propertize date 'face 'elfeed-search-date-face) " ")
    (insert (propertize (elfeed-format-column
                         title (elfeed-clamp 12 title-width 60) :left)
                        'face (elfeed-search--faces-for-entry entry)) " ")
    (when tags-str
      (insert "(" tags-str ") "))))

(setq elfeed-search-print-entry-function #'my/elfeed-search-print-entry)
```

效果：搜索列表中 `unread` 变为 `UR`，其他标签（如 starred）不受影响。

### 整体评价

浏览器方案（Feedly/Inoreader/Pocket）需要频繁切到浏览器，容易被其他标签页分心。**Spacemacs + elfeed** 全程终端内操作，纯键盘，离线可用，阅读笔记直通 org-mode 知识库。
