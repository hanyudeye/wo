# 远程工作·平台清单与 FIRE 路径

> 目标：用远程高薪 + 低成本生活 = 高储蓄率，加速 FIRE
> FIRE = 攒够被动收入覆盖开支；真正杠杆是**储蓄率**，不是收入绝对值

## 一、远程全职岗位（按月发薪，现金流稳）

### 国际（收入上限高，需英语）

- We Work Remotely / RemoteOK / Remotive / Himalayas / Working Nomads — 职位聚合，看有没有 `Anywhere in the World`
- Turing / Arc.dev — 面向美国企业的开发者匹配，薪资接近硅谷
- Wellfound（原 AngelList）/ YC Work at a Startup — 创业公司远程岗

### 国内（中文、同时区）

- 电鸭社区 eleduck.com — 国内远程工作社区代表
- V2EX「酷工作」、即刻、BOSS直聘（筛「远程」）

## 二、接单 / 自由职业（单价高、时间灵活）

| 平台 | 适合谁 | 收入区间 | 抽成 |
|------|--------|----------|------|
| Upwork | 英语好、能写提案 | $30-150/hr | 0-15% |
| Toptal | 资深（前 3%） | $60-200/hr | 0（客户付） |
| Fiverr | 能拆成标准套餐 | $5-500/单 | 20% |
| Freelancer | 新手练手 | $15-75/hr | 10% |
| PeoplePerHour | 英文提案、欧洲单 | — | 3.5-20% |
| 程序员客栈 | 中文、有经验 | — | 托管结算 |
| 猿急送 | 在职、短单快匹配 | — | 8.6% |
| 实现网 | 会开发、担保交易 | ¥ 中位 1.2 万/单 | 10% |
| 猪八戒 / 一品威客 | 纯新手练手 | 低 | 10-20% |

- 国内尽量选**有资金托管**的（程序员客栈、实现网、猪八戒、一品威客）
- 国际优先 **Upwork**（性价比）/ **Toptal**（突破天花板）

## 三、社区 / 私域（无抽成，靠个人 IP）

- 电鸭社区发长帖：把技术栈、项目经历写清楚
- GitHub 高 star 项目、技术博客 = 最好的简历
- Telegram / Discord 技术群（Web3、AI 单子多）

## 四、怎么选（决策）

- 英语流利 + 3 年以上 → Upwork，冲 Toptal
- 中文 + 想稳定 → 电鸭 / 程序员客栈
- 只做标准小活（爬虫、脚本、页面）→ Fiverr
- 纯新手 → 猪八戒 / 一品威客积累评价，或先做非技术类
- 目标是长期远程岗 → We Work Remotely / RemoteOK / 电鸭

## 五、行动清单（分阶段）

1. **打底**：完善英文简历 + 作品集（GitHub / 博客链接放最前）
2. **注册**：选 1 主 + 2 副平台，资料填满（技术栈、可工作时间、期望报价）
3. **起步**：先接 2-3 个小单攒评价，别一上来冲高价
4. **放大**：好评 > 90% 后，咨询转化率明显上升，再抬高报价
5. **私域**：稳定客户转到私域，减少对平台依赖

## 六、避坑与风控

- 只用**平台托管付款**，不私下转账、不接受口头付款约定
- 开工前写清需求文档 + 验收标准 + 免费修改次数
- 分阶段收款，至少 30% 预付款
- 同时进行的需求 ≤ 2-3 个，别接过量毁交付

## 七、FIRE 财务视角

- 接单是**线性收入**，只有高时薪才撑得起储蓄率；优先「按小时/高时薪」而非低价计件
- **地域套利**：赚美元/欧元，在低成本城市生活，储蓄率可达 50%+
- 组合打法：稳定远程全职（保底）+ 1-2 个高价接单（增收）
- 提醒：接单只是工具，**储蓄率**才是 FIRE 的真正杠杆
