# 3. 最低成本自学路线

如果目标是**尽可能少花钱，同时真正把分数考出来**，我建议：

> **官方真题 + 英语输入 + 写作/口语反馈**

而不是：

> 买一堆教材 → 看大量课程 → 做笔记 → 很少做题。

### 第一阶段：先测真实水平

花 **1天**。

直接做一次完整模拟：

**Listening + Reading + Writing + Speaking**

不要查词，不暂停，严格计时。

然后记录：

```text
Listening：？
Reading：？
Writing：？
Speaking：？
Overall：？
```

这一步非常重要。

你之前让我测试英语水平，如果你现在准备认真考 IELTS，我建议不要凭“感觉”判断水平，**直接用官方模拟题测一次**。

---

# 第二阶段：确定主要短板

假设你测出来：

| 项目        |  分数 |
| --------- | --: |
| Listening | 6.5 |
| Reading   | 6.5 |
| Writing   | 5.0 |
| Speaking  | 5.5 |

那么你不应该四项平均用力。

应该：

**Writing 40% + Speaking 30% + Listening 15% + Reading 15%**

因为听读已经够用，继续大量刷题的边际收益很低。

---

# 第三阶段：每天 60～90 分钟

我比较推荐这个结构：

### 20分钟：Listening

做一组题：

> 做题 → 对答案 → 重听错题 → 看 transcript → 找出没听懂的原因

不要只统计：

> 30题对25题

真正要找：

> **为什么错？**

例如：

* 单词没听出来
* 连读没听出来
* 拼写错误
* 定位错误
* 被干扰项骗了
* 注意力丢失

---

### 20分钟：Reading

不要每天做完整三篇。

可以：

> 一篇 → 限时 → 对答案 → 分析错误

重点训练：

**定位 → 同义替换 → 判断题型 → 排除干扰项**

IELTS Reading 很大程度上是一个**信息检索和同义改写识别问题**。

---

### 20～30分钟：Writing

这是自学最困难的部分。

不要每天写完整作文。

可以采用：

**第一天：Task 1**

**第二天：Task 2**

然后建立自己的：

```text
开头模板
论证结构
连接方式
常见语法错误
常用表达
```

但不要背一篇完整范文。

---

### 10～20分钟：Speaking

这是你完全可以利用 ChatGPT 的地方。

例如直接让我扮演考官：

> IELTS Speaking Part 1，严格按照真实考试方式提问，不要提示答案。结束后给我 Band 评分和错误分析。

然后：

**回答 → 转录 → 找错误 → 重答**

比单纯背 Speaking 模板有效。

### 最值得花钱的只有一个地方

**Writing / Speaking 的人工反馈。**

如果你自己已经能稳定做到：

> Reading 7
> Listening 7
> Speaking 6
> Writing 5.5

那么继续买大量课程基本没有意义。

真正的瓶颈是：

> **为什么 Writing 上不了 6.5？**

这时候花少量钱找专业老师批几篇作文，往往比买几千元课程划算。
