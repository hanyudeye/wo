# 日本旅游

## 行前准备清单

- 身份证
- [ ] 护照（有效期 >6 个月）
- [ ] 签证（单次/三年/五年）
- [ ] 机票（往返，入境可能检查）
- [ ] 酒店预订（全程，入境可能检查）
- [ ] Visit Japan Web 提前填好（入境 QR 码 + 海关申报 QR 码）
- [ ] 流量卡（20~50 元/7 天，或开通国际漫游）
- [ ] Suica/PASMO 交通卡（iPhone 直接加钱包，无需实体卡）
- [ ] 充电宝（日本共享充电宝少）
- [ ] 零钱包（硬币很多）
- [ ] 垃圾袋（日本公共垃圾桶极少）
- [ ] 餐巾纸/湿巾（公共洗手间不一定有擦手纸）
- [ ] 一次性雨衣/折叠伞

## 签证

- 不能个人送签，需通过指定旅行社代办
- 单次旅游签证：**签证费约 200 + 代办费 100~400 = 总计 300~600 元**
- 三年/五年多次签：费用更高，需在职/资产证明
- 存款证明建议：单次 5~10 万，多次 20 万+
- 出签时间：约 5~10 个工作日

## 住宿

- **胶囊旅馆/青旅**：80~150 元/晚，适合单人穷游
- **商务酒店**（东横 INN、APA）：300~600 元/晚，干净且位置好
- **民宿**：Airbnb 约 300~800 元/晚，适合多人
- 东京最贵，大阪/京都相对便宜

### 胶囊旅馆怎么预定

推荐平台（按优先顺序）：

| 平台 | 特点 |
|------|------|
| **Agoda** | 日本胶囊旅馆房源最全，价格常比 Booking 便宜 10~20% |
| **Booking.com** | 可免费取消，界面友好 |
| **Trip.com** | 国内用户方便，中文客服 |
| 现场直接入住 | 部分胶囊可 walk-in，但旺季不建议 |

**注意事项：**
- 男女分开（多数胶囊旅馆有独立楼层/区域，女生不用担心）
- 入住时间通常下午 3~4 点后，早上 10 点前要退房（白天无法待在房间）
- 大件行李通常有储物柜或前台寄存，但储物空间有限（推荐带 20 寸登机箱，28 寸大箱子可能塞不进）
- 入住前确认有无**独立空调**（部分老胶囊的通风/空调是中央式，夏天偏闷）
- 公共卫浴，一般提供洗浴用品和毛巾，但牙具/拖鞋建议自备

**搜索技巧：** 在 Agoda / Booking 搜 "カプセルホテル" 或 "Capsule Hotel"，按高分排序（8.0+ 一般体验不错），优先选带 "大浴場"（公共浴池）的，睡前泡澡很舒服。

**推荐几家口碑稳定的：**
- 大阪：**First Cabin（御堂筋心斋桥）** — 头等舱风格，150 元左右
- 东京：**Nine Hours（新宿/赤坂）** — 简约干净，120~180 元
- 东京：**Anshin Oyado（新宿）** — 带大浴场，150~200 元

### 在线预定支付技巧

Agoda 上订胶囊/酒店，用汇丰香港信用卡最划算：

- 结算时**币种选日元（JPY）**，不要选人民币（CNY）
- 汇丰香港 Visa/Mastercard **免外币交易手续费**
- 汇率走 Visa/Mastercard 当天牌价，比 Agoda 自定汇率好 2~3%
- 部分卡种有额外返现/积分（HSBC Red、EveryMile 等）
- 最终账单以港币出，汇丰自动按 Visa 汇率折算，无额外费用

其他信用卡同理：优先选 **免外币手续费 + 币种选当地货币（JPY）**。

## 交通

- **Suica / PASMO**：最方便，全日本通用（部分新干线除外），iPhone 直接 Apple Pay 充值，不用买实体卡
- **JR Pass**：跨城多的话才划算（如东京→大阪→京都），单城游不需要
- **出租车**：很贵（起步价约 40 元），非紧急不建议
- 市内一日券（地铁/巴士）约 50~80 元，一天跑 3+ 景点才划算

## 购物

### 药妆推荐

- 口腔溃疡：**大正口内软膏 / 口内炎パッチ**
- 蚊虫叮咬：**无比滴 / ムヒ**
- 疤痕：**小林制药 疤痕凝胶 / メディキュア**
- 感冒药：**大正感冒药**
- 止痛药：**EVE**
- 保健品：**DHC 维生素系列**（国内半价）

### 好逛的店

- **Loft / 东急手创（Hands）** — 生活杂货、文具
- **BicCamera / 友都八喜** — 电器、药妆
- **唐吉诃德** — 深夜也能逛，东西杂但便宜
- **松本清 / SUNDRUG** — 药妆连锁，满额免税+优惠券
- **3Coins / Seria** — 百元好物

### 省钱技巧

- 免税门槛：同一店铺同日满 5500 日元（约 275 元）免 10% 消费税
- BicCamera、松本清、唐吉诃德有**游客额外优惠券**（3%~7%），小红书/微信公众号搜二维码
- 二手推荐：**秋叶原 Janpara / 2nd Street** — iPhone、iPad、古着，性价比高

## 电压提醒

日本电压 **100V**（东日本 50Hz / 西日本 60Hz）。

- 手机、相机、笔记本充电器：通常支持 100~240V，**可直接用**
- 电饭煲、卷发棒、吹风机：很多仅支持 100V，**回国需变压器**
- 买电器前确认电压标识

## 5~7 日行程推荐

### 经典关西线（大阪·京都·奈良）

适合第一次去日本，关西机场进出，文化+美食+城市都能体验。

| 天数 | 上午 | 下午 | 晚上 |
|------|------|------|------|
| **Day 1** | 抵达关西机场 → 大阪市区酒店 | 心斋桥、道顿堀逛街 | 道顿堀吃大阪烧/章鱼烧 |
| **Day 2** | 大阪城公园 | 通天阁、新世界 | 梅田蓝天大厦看夜景 |
| **Day 3** | 乘 JR 去京都（30min）→ 清水寺 | 二年坂/三年坂 → 八坂神社 | 衹园/花见小路散步 |
| **Day 4** | 伏见稻荷大社（千本鸟居） | 乘 JR 去奈良（45min）喂鹿 | 回大阪，逛唐吉诃德补货 |
| **Day 5** | 大阪环球影城 USJ（整日） | — | — |
| **Day 6**（可选） | 京都岚山竹林、天龙寺 | 金阁寺 | 京都站拉面小路 |
| **Day 7**（可选） | 临空奥特莱斯（关西机场旁） | 机场免税店 | 返程 |

### 东京线

适合喜欢城市、购物、二次元，东京进出。

| 天数 | 上午 | 下午 | 晚上 |
|------|------|------|------|

### 省钱版（适合学生/穷游）

| 天数 | 安排 | 住宿 |
|------|------|------|
| **Day 1** | 抵达关西机场 → 逛道顿堀 + 唐吉诃德 | 大阪胶囊旅馆 |
| **Day 2** | 大阪城公园（免费）→ 心斋桥逛街 | 大阪胶囊旅馆 |
| **Day 3** | 京都清水寺 → 伏见稻荷大社（免费） | 京都青旅 |
| **Day 4** | 奈良公园喂鹿（免费）→ 回大阪 | 大阪胶囊旅馆 |
| **Day 5** | 大阪市内闲逛 → 返程 | — |

**省钱要点：**
- 住宿选胶囊/青旅，约 80~150 元/晚
- 正餐用便利店（全家/7-11/罗森）解决早餐和午餐，便宜且好吃
- 景点多选免费的（神社、公园、逛街本身就是体验）
- 交通靠步行+单程票，不买 JR Pass（5 天关西线 JR Pass 不划算）
- 唐吉诃德买零食和药妆退税，凑满 5500 日元免税门槛
